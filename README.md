# Prova-DSW
Etapa 1

Passo a passo de como rodar o projeto após clonar:
No terminal, crie o ambiente virtual e o nomeie (geralmente nomeado venv):
python -m venv venv 

Ative o ambiente virtual:
venv/Scripts/Activate

Installe o django:
pip install django

Para aplicar as migrações:
python manage.py migrate
